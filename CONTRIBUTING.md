# Corrections to the October 2026 edition

Watershed Wednesday is a dated operations guide compiled on October 22, 2026. Contributions should correct or clarify that edition. This repository does not promise an ongoing security-news or advisory feed.

For a correction, identify the incident number and the exact sentence or table cell, propose replacement wording, and link to the primary source that supports it. Include the source's publication or revision date when available. If guidance changed after compilation, distinguish the later update from what the original edition recorded.

Prefer vendor advisories, operator statements, CVE records, government alerts, regulatory filings and the discovering researcher's original report. Use secondary reporting for context and label it clearly. Keep source numbering stable where practical, and retain attribution and unresolved questions that still matter to the action.

Do not infer exploitation from the existence of a proof of concept, treat a reachable link as verification, or expand an IOC list with unsourced values. Check hashes, domains, IPs, version cutoffs and remediation instructions directly against their cited sources. Defang suspicious domains consistently with the surrounding note; avoid turning indicators into clickable destinations.

Edit the Markdown and site source files, then run `npm ci` and `npm run build`. For presentation changes, preview the result with `npm run preview` and inspect both narrow and wide layouts. Check incident links and preserve the website's reduced-motion and static-background behavior.

Keep generated output, downloaded source captures, credentials, personal workflow notes and machine-specific file paths out of contributions. Public references should resolve to an upstream source or a file actually included in this repository.
